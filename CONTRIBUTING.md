# Contribuer à XWIN

## Processus

1. Ouvrir une issue (bug / feature / sécurité) avec le template adapté.
2. Créer une branche `feat/...`, `fix/...` ou `chore/...` depuis `main`.
3. Ne jamais commiter de secrets, `.env`, clés Stripe, tokens Vercel ou GitHub.
4. Ouvrir une Pull Request vers `main`.
5. Attendre la CI. Demander une revue si des CODEOWNERS sont définis.

## Sécurité

Les rapports de vulnérabilités sensibles ne doivent pas être déposés en issue publique. Utiliser le canal privé du maintainer.
